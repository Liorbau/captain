# Captain

[![CI](https://github.com/Liorbau/captain/actions/workflows/ci.yml/badge.svg)](https://github.com/Liorbau/captain/actions/workflows/ci.yml)

**You're the captain. The AI is the crew.**

Captain is a small command-line tool (`cptn`) that drops a shared AI engineering
policy into any repo, so coding agents respect engineering ownership, design
control, and quality gates — while you keep the helm.

Works with:
- Claude Code
- Cursor
- other AI coding agents that read `AGENTS.md`

> **Built by its own rules.** Captain was generated by AI under human command —
> the captain set the course and made the calls; the crew (the AI) did the
> rowing. Living proof you can ship real software and still be the captain.

## Install the `cptn` command (once per machine)

macOS and Linux:

```bash
curl -fsSL https://raw.githubusercontent.com/Liorbau/captain/main/bootstrap.sh | bash
```

This installs `cptn` to `~/.local/bin` and makes sure it's on your `PATH`.
Open a new terminal (or `source` your shell profile) and you're set.

Don't want the installer touching your shell config? Skip the `PATH` edit:

```bash
curl -fsSL https://raw.githubusercontent.com/Liorbau/captain/main/bootstrap.sh | bash -s -- --no-modify-path
```

> Prefer to read before you run? Inspect the script first:
> ```bash
> curl -fsSL https://raw.githubusercontent.com/Liorbau/captain/main/bootstrap.sh -o bootstrap.sh
> less bootstrap.sh
> bash bootstrap.sh
> ```

## Use it

From inside any git repository:

```bash
cptn init      # install/refresh the policy in this repo
cptn status    # show whether the policy is installed here
cptn update    # pull the latest policy (safe to re-run)
cptn help      # all commands
```

Captain writes the policy into just two files — `AGENTS.md` (read by Cursor and
other agents) and `CLAUDE.md` (read by Claude Code) — inside a managed block
delimited by HTML comments. It's safe to run in a repo that already has its own
`AGENTS.md` or `CLAUDE.md`:

- If the file doesn't exist, `cptn` creates it as just the managed block.
- If it exists, `cptn` appends the block, preserving everything you wrote.
- On `cptn update`, only the content **inside** the managed block is refreshed;
  the rest of your file is never touched.

Nothing else is installed and nothing is ever deleted.

## Windows

Captain is a shell tool, so native Windows (PowerShell/cmd) isn't supported
directly. Run it inside one of these and everything works as on Linux:

- **WSL** (recommended): install [WSL](https://learn.microsoft.com/windows/wsl/install),
  open your Linux shell, then run the install command above.
- **Git Bash** (ships with [Git for Windows](https://git-scm.com/download/win)):
  open Git Bash and run the install command above.

## Security

Captain installs via `curl | bash`, the same model as Homebrew, `rustup`, and
`nvm`. That means you are trusting this repository to run code on your machine.
To keep that trust well-placed:

- All downloads use **HTTPS** (GitHub enforces TLS).
- **Pin to a published release tag** for reproducible installs instead of
  tracking `main` (use any tag from the repo's
  [Releases](https://github.com/Liorbau/captain/releases) page):
  ```bash
  CAPTAIN_REF=v0.1.1 cptn update
  ```
  Until a release is tagged, `cptn` tracks `main`.
- The scripts are small — **read them before running** (see the inspect-first
  snippet above).

If this repository or its owner's account were ever compromised, a malicious
version could be served. That risk is inherent to any `curl | bash` installer;
pinning to a known-good tag is your best mitigation.

## Philosophy

AI agents may write code, but the human engineer owns:

- architecture
- tradeoffs
- system boundaries
- data models
- API contracts
- quality gates
- final decisions

The full policy lives in [`AGENTS.md`](AGENTS.md).
